# SRT EN → JP

英語SRT字幕ファイルの行番号・タイムコード・空行構成を完全維持したまま、Gemini APIを用いて自然な会話調の日本語字幕に翻訳するWebアプリです（Vercel対応）。

## 主な機能

- **SRT構造保護**: 行番号・タイムコード・空行位置を崩さず、英文字幕行のみを抽出して翻訳・置換
- **字幕特化の翻訳ルール**: 前後の文脈を考慮し、「自然な会話調」「呼称・口調の統一」「字幕らしい簡潔さ」を重視したGeminiプロンプト設計
- **スクロール同期 & 行位置インジケーター**: オリジナルと日本語字幕の画面スクロールをリアルタイム同期し、現在表示中の行番号範囲（例: `表示: 45〜62行 / 全540行`）をバッジ表示
- **モデル選択 & 文脈考慮モード**: `gemini-2.5-flash`（推奨・高速）、`gemini-2.5-flash-lite`（超高速）、`gemini-2.0-flash` などから選択可能。「文脈考慮（前後の台詞の流れを反映）」または意訳暴走を防ぐ「独立翻訳（各行独立）」を切り替え可能
- **リアルタイム通信モニター（ライブログ）**: 各バッチの送信状況、応答待機秒数（ストップウォッチ）、HTTPステータス、消費トークン数をリアルタイムに可視化。ログのワンクリックコピーに対応
- **タイムコード修正（表示時間1秒延長・重複防止）**: 字幕の表示終了時刻をワンクリックで1秒延長。次の字幕と重複する場合は次字幕の開始1ms前までに自動制限し、チラつきやプレイヤーのバグを防止
- **エラー安全中断機能**: エラー等により未翻訳（原文のまま）となった行が100行を超えた場合、不要なAPI呼び出しを防ぐため処理を自動中断して警告表示
- **厳密な整合性検証**: 出力前に元ファイルと行単位で比較検証し、構造に狂いがない場合のみSRTダウンロード（UTF-8）を許可
- **消費推定トークン数表示 & AI Studioリンク**: 処理ごとの消費トークン数を可視化し、無料枠の残量確認（Google AI Studio）リンクを配置

## Vercelへのデプロイ手順

1. このリポジトリをVercelへImportします（Framework Presetは `Other` でOK）。
2. Vercelの **Settings → Environment Variables** に `GEMINI_API_KEY` を追加します（Google AI Studioで取得したAPIキー）。
3. （任意）デフォルトモデルを変更したい場合は `GEMINI_MODEL`（例: `gemini-2.5-flash`）を設定します。
4. Deployします。

※ APIキーはクライアント（ブラウザ）へは一切渡されず、サーバーサイドの `/api/translate` 経由でのみ安全にGemini APIと通信します。

## 翻訳の仕組み

1. ブラウザ側でSRTファイルを解析し、英文字幕行を25行単位のバッチに分割します（Vercelの関数実行時間制限でのタイムアウトを防止）。
2. Gemini APIのレート制限（無料枠15 RPM等）を超過しないよう、クライアント側でリクエスト間隔を制御し **RPM ≤ 10**（最小間隔6.2秒）を維持しながら順次送信します。
3. `/api/translate` 経由でGemini APIのStructured Outputs（JSON Schema）を用いて高品質な日本語字幕を取得します。改行の自動サニタイズや行単位の柔軟なフォールバックにより高い堅牢性を確保しています。
4. サーバーとブラウザの双方で、行番号の対応・改行の非混入・行数の一致を二重に検証します。
5. メイン翻訳後に未翻訳や英文が残った行を自動検出し、小バッチで再翻訳を行う**自動回収フェーズ（後処理）**を実行します。
6. バッチ失敗時は自動リトライ（レート制限時は待機時間を延長）し、未翻訳行が100行を超えた場合は処理を安全に中断します。
7. 翻訳完了後、画面上で自由に手動修正でき、整合性が確認され次第 `.srt` ファイルとしてダウンロードできます。
